# Identidad visual

Aquí se almacenan el logotipo principal, sus variantes horizontal, vertical, clara y oscura, el isotipo y otros recursos visuales de marca.

Usar nombres descriptivos en minúsculas, con guiones medios, sin espacios ni tildes; por ejemplo, `orman-logo-horizontal.svg`. Se recomienda SVG para logotipos e identidad vectorial, y PNG únicamente si se requiere transparencia que SVG no pueda resolver.

No guardar información sensible en archivos, metadatos o nombres. Optimizar cada imagen antes de incorporarla.
