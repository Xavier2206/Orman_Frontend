# Imágenes del hero

Aquí se almacenan fotografías, composiciones y fondos visuales destinados al hero o portada pública.

Usar nombres descriptivos en minúsculas, con guiones medios, sin espacios ni tildes; por ejemplo, `edificio-orman-portada.webp`. Se recomiendan WebP o AVIF para fotografías, PNG cuando la transparencia sea necesaria y JPG solo por compatibilidad.

No guardar información sensible en archivos, metadatos o nombres. Optimizar cada imagen antes de incorporarla.
