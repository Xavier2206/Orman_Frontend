# Imágenes de reemplazo

Aquí se almacenan reemplazos para propiedades sin fotografía, recursos temporales del hero e imágenes de carga o sustitución visual.

Usar nombres descriptivos en minúsculas, con guiones medios, sin espacios ni tildes; por ejemplo, `property-placeholder.svg`. Se recomienda SVG para ilustraciones vectoriales, WebP o AVIF para recursos rasterizados, PNG si se requiere transparencia y JPG solo por compatibilidad.

No guardar información sensible en archivos, metadatos o nombres. Optimizar cada imagen antes de incorporarla.
