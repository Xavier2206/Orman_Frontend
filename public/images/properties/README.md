# Fotografías de propiedades

Aquí se almacenan fotografías de casas, edificios, departamentos, tiendas, oficinas, garajes y sus ambientes. No crear subcarpetas por propiedad hasta que la organización futura lo requiera.

Usar nombres descriptivos en minúsculas, con guiones medios, sin espacios ni tildes; por ejemplo, `departamento-02-sala.webp`. Se recomiendan WebP o AVIF para fotografías, PNG cuando la transparencia sea necesaria y JPG solo por compatibilidad.

No guardar información sensible en archivos, metadatos o nombres. Optimizar cada imagen antes de incorporarla.
