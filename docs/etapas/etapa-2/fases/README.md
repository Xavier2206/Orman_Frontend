# Fases de la Etapa 2

Esta carpeta contiene las fases funcionales de la Etapa 2.

Las fases se documentan conforme se desarrollan. La Fase 01 de integración de autenticación, la
Fase 13 canónica de Propiedades, la Fase 14 de Listado de Unidades y la Fase 15 de Compactación y
acciones de Unidades están documentadas y completadas; el módulo de Propiedades reúne
en un único documento su listado, CRUD, portada, selector, ubicación cartográfica, layout y
correcciones técnicas. Los ajustes pequeños de una fase activa deben documentarse dentro del
documento correspondiente y no generar automáticamente una nueva fase. Las fases posteriores
requieren definición y autorización explícita.
