# Fases de la Etapa 2

Esta carpeta contiene las fases funcionales de la Etapa 2.

Las fases se documentan conforme se desarrollan. La Fase 01 de integración de autenticación, la
Fase 13 canónica de Propiedades, las Fases 14 y 15 de Unidades y las Fases 16, 17, 18, 19, 20, 21, 22 y 23 de Contratos
están documentadas y completadas. El módulo de Propiedades reúne en un único documento su listado,
CRUD, portada, selector, ubicación cartográfica, layout y correcciones técnicas. Los ajustes
pequeños de una fase activa deben documentarse dentro del documento correspondiente y no generar
automáticamente una nueva fase. Las fases posteriores requieren definición y autorización explícita.
